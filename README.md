# Catálogo de sagas de películas

Este repositorio contiene un pequeño catálogo de sagas cinematográficas: La Guerra de las Galaxias, Harry Potter y El Señor de los Anillos.
Cada saga tiene su propia carpeta con un archivo de prólogo (xxx_prologo.txt) que resume la historia y un archivo de capítulos (xxx_capitulos.txt) con el listado de sus películas.
El catálogo servirá como base de contenidos para una futura web de sagas de películas.
Se ha creado en la Práctica 1 de Entornos de Desarrollo para practicar el trabajo con Git en local y con GitHub.
